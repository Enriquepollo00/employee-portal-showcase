# Employee & Student Information Portal

Overview

-This project showcases the modernization of legacy employee and student information stored within an IBM AS/400 (IBM i) environment into a modern, secure web-based application.
-The project involved extracting and working with legacy DB2/AS400 data, preparing and migrating selected datasets into MySQL, and developing a web portal using Java, Spring Boot, Thymeleaf, and Spring Security.

-The goal was to provide a more accessible and user-friendly interface for authorized users to search and view employee and student information while implementing authentication and role-based access controls.

# Project Modernization Process

The project followed a modernization workflow:

IBM AS/400 (IBM i) / DB2
↓
Legacy Data Identification & Analysis
↓
Data Extraction & Transformation
↓
MySQL Database
↓
Spring Boot Backend
↓
Spring Security & Role-Based Access Control
↓
Thymeleaf Web Interface

Working with the legacy environment required identifying the appropriate AS/400 files and fields, understanding existing data structures, extracting the required information, and preparing it for use within the modern application.
